# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and constructive, assume good intent, and help keep the community welcoming to everyone, whatever their experience, background or identity. Harassment and personal attacks are not tolerated.

To report unacceptable behaviour, use GitHub's private vulnerability reporting (see [SECURITY.md](SECURITY.md)) or contact the maintainer through their GitHub profile. Reports are handled confidentially.
